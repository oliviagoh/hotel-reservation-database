# Hotel Reservation Database

## Overview

A relational database system designed to manage hotel
customers, rooms, reservations and payments.

## Technologies

- Oracle SQL
- SQL Developer

## Database Design

The system consists of:

- Customer
- Hotel
- Room
- Reservation
- Payment

## Key Features

- Customer management
- Room management
- Hotel management
- Reservation tracking
- Payment tracking
- SQL reporting queries

## SQL Concepts Demonstrated

- Primary Keys
- Foreign Keys
- JOIN
- GROUP BY
- Aggregate Functions
- Subqueries
- Data Integrity
